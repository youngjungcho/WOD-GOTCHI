# WOD-GOTCHI 게임 설계 (MVP 기준)

## 콘셉트
크로스핏 박스에 처음 등록한 초보 한 명을 직접 만들고, 매일 돌봐서 게임즈 선수로 키우는 다마고치형 게임.
실시간으로 시간이 흐르고, 하루 3~5분 플레이를 목표로 한다.

## 확정 사항
| 항목 | 결정 |
|---|---|
| 엔진 | Godot 4 (GDScript), iOS/Android 세로 화면 |
| 해상도 | 180×320 기준, 정수배 확대, nearest 필터 |
| 폰트 | Galmuri9 / Galmuri11 (SIL OFL) |
| 방치 페널티 | 단계별 점진 강화 (아래 표) |
| 실제 운동 연동 | 실제 PR/운동 체크인 → 보너스 |
| WOD | 플레이어가 직접 짜서 실행 |
| 캐릭터 | 이름·피부·헤어·헤어색·운동복 색 선택 |

## 게이지 (0~100, 시간에 따라 감소)
- 영양 / 에너지 / 의욕 / 컨디션

### 방치 페널티 단계
| 단계 | 감소 배율 | 바닥값(오프라인) | 디트레이닝 |
|---|---|---|---|
| 0 등록생 | 0.5 | 35 | 없음 |
| 1 스케일드 | 0.7 | 25 | 없음 |
| 2 RX | 1.0 | 10 | 없음 |
| 3 컴피티터 | 1.2 | 0 | 24시간 넘게 방치 시 하루당 XP 소폭 감소 |
| 4 게임즈 선수 | 1.4 | 0 | 동일 (조금 더 큼) |

## 능력치
STR(근력) / GYM(체조) / ENG(엔진) / TEC(기술). 각각 XP → 레벨.

## 성장 단계
등록생 → 스케일드 → RX → 컴피티터 → 게임즈 선수.
조건: 능력치 레벨 합계 + 키운 일수. RX부터 가장 높은 능력치에 따라 칭호 분기
(바벨 괴물 / 체조 요정 / 카디오 머신 / 올라운더).

## 미니게임
### 1RM 챌린지 (연타)
- 하루 3번의 시기(attempt). 회당 에너지 소모.
- 바 위치를 연타로 끌어올림. 무게/역량 비율에 따라 내려가는 힘이 커지고, 스티킹 포인트 구간에서 저항 증가.
- 역량 = 근력 레벨 + 당일 컨디션(에너지·의욕·컨디션).

### 풀업 계열 리듬게임
- 스트릭트 풀업(A 단타) / 버터플라이(A·B 교대, 빠름) / 머슬업(킵 2번 + 길게 누르기).
- Perfect / Good / Miss, 3연속 미스 시 바에서 떨어짐. GYM 레벨이 판정 범위를 넓힘.

### 내가 짠 WOD
- 동작 최대 4개 + 횟수 + 라운드 수. 풀업 계열은 리듬 구간, 나머지는 연타 구간으로 실행.
- 볼륨만큼 해당 능력치 XP 획득, 에너지 소모.

## 실제 운동 연동
- "오늘 실제로 운동했어요" 하루 1회 체크인 → 의욕 + XP 보너스.
- 실제 PR 입력(데드리프트·스쿼트·클린·스내치 kg, 최대 풀업 개수) → 기록 갱신 시 1회성 보너스.

## 이후 버전
클린/스내치 1RM, 진화별 스프라이트, NPC, 시즌 이벤트, 푸시 알림, 장비.

## 운동 시스템 (v2)
- 동작 62종, 4개 카테고리: 바벨 18 / 케틀벨·덤벨·기타 11 / 체조 20 / 카디오 13 (`scripts/moves.gd`).
- 동작마다 1회당 XP가 [근력, 체조, 엔진, 기술]로 다르게 분배된다. 전체 배율 `XP_SCALE = 0.5`.
- 고급 동작은 능력치 레벨로 해금되고, 잠긴 동작은 실행 시 스케일 동작으로 자동 대체된다.
- 체조 동작은 리듬 패턴이 각각 다름 (예: 토투바 `ab`, 머슬업 `aaA.`, 로프 `abab`, 스트릭트 HSPU `A.`).
- 다양성 보너스
  - 최근 3일 같은 동작 횟수: 0회 x1.3 / 1회 x1.1 / 2회 x1.0 / 3회 x0.85 / 4회 x0.7 / 5회+ x0.6
  - 오늘의 추천 3동작(카테고리 서로 다름): x1.5
  - 한 세션에 섞인 카테고리 수: 2개 x1.1 / 3개 x1.2 / 4개 x1.3
- 운동하기 메뉴: 자유 운동(카테고리 → 동작), 내 WOD, 1RM 챌린지.

## 진화 · 도감 (v3)
- 진화형 23종 (`scripts/forms.gd`). 단계가 오를 때 키운 방식으로 결정되고 외형(체형·액세서리)이 바뀐다.
- 숨겨진 분기: 치팅 비율 45% 초과 → 먹방/치팅데이 킹/피자 챔피언, 부상 3회 이상 → 유리몸/불사조,
  멘탈 70 이상 → 멘탈 갑, 무부상 + 멘탈 70 + 균형 + 무시 3회 이하 → 레전드.
- 진화 연출(실루엣 깜빡임) 후 도감 등록. 도감은 `user://dex.json`에 따로 저장되어 새로 시작해도 유지.

## 호출 · 훈육 · 멘탈 (v3)
- 진짜 호출(배고픔/졸림/땀/심심함)은 필요가 생기면 바로, 꾀부림(가짜 배고픔/치킨/땡땡이/가짜 졸림)은 40~120분 간격(멘탈 낮을수록 자주).
- A 들어주기 / B 단호하게. 꾀부림을 거절하면 멘탈 +8, 들어주면 멘탈 -5. 진짜 호출을 혼내면 기분 -10.
- 30분 안에 반응하지 않으면 무시 기록(진화 분기에 반영), 등록생·스케일드는 페널티 절반.
- 멘탈은 1RM 역량(최대 +4%)과 진화 분기에 영향.
- PC 테스트 키: F1 호출, F2 6시간 경과(+운동한 날 1일), F3 모든 능력치 +50 XP.
- 진화 조건: [레벨 합, 실제로 운동한 날] = 스케일드 12/2, RX 20/5, 컴피티터 32/12, 게임즈 48/25.

## 1RM 4종목 (v4)
| 종목 | 해금 | 단계 | 역량 공식(기본) |
|---|---|---|---|
| 데드리프트 | 기본 | 연타 | 40 + 근력×8 + 기술×2 |
| 백스쿼트 | 기본 | 깊이 타이밍 → 연타 | 데드 × 0.85 |
| 클린 | 기술 Lv.2 | 연타(풀) → 받기 타이밍 → 연타(일어서기) | (40 + 근력×6 + 기술×5) × 0.7 |
| 스내치 | 기술 Lv.3 | 연타(풀) → 좁은 받기 → A·B 균형 | (40 + 근력×5 + 기술×6) × 0.55 |
- 레벨은 (Lv-1) 기준. 역량 × 컨디션(에너지·몸·기분·멘탈).
- 받기 존 너비 = 기본 × (1 + 기술×0.06) / (무게비율²). PERFECT 캐치·반동은 다음 연타에 시작 보너스.
- 종목별 PR, 종목마다 하루 3번 시기.

## 성장 속도 (v5)
- 레벨 곡선: 누적 XP = 9×(Lv-1)² + 16×(Lv-1) → Lv2 25 / Lv3 68 / Lv5 208 / Lv8 553 / Lv12 1265.
- 하루 운동 세션 3번까지 경험치 100%, 4번째부터 50% (1RM 시기는 세션에 포함하지 않음).
- 추정: 가볍게(하루 1 WOD) 게임즈까지 약 6주, 열심히(하루 3 WOD) 약 25일(운동한 날 조건이 제한).

## WOD 플레이 (v6, scripts/screens/wod_play.gd)
- 한 화면에서 라운드×동작을 이어서 진행. 자유 운동도 1라운드 WOD로 실행.
- 동작별 조작(Moves.input_of): power(파워 게이지 초록에 A, 퍼펙트 콤보) / rope(줄이 발밑일 때 A, 실패 시 줄 걸림)
  / cadence(A·B 일정 간격, 스트로크 2번=1회) / combo(버튼 순서) / beat(체조 리듬 패턴, 3연속 미스 시 미끄러짐).
- 심박: 입력마다 상승(엔진 레벨이 높을수록 덜 오름), 손을 떼면 하강. 85+ 판정 범위 60%, 100이면 55까지 강제 휴식.
- 라이벌 토리: 동작별 기준 시간 × (1.25 − 0.03×평균 레벨). 이기면 보너스. 같은 WOD의 최고 기록(best)은 고스트 마커와 PR 보너스.
- 코치 대사: 동작 시작, 3개 남음, 심박 경고, 강제 휴식, 역전, 마지막 라운드.

## 잠 · 쉬는 동안 콘텐츠 (v7)
- 잠: 에너지 시간당 +40, 밤(23~7시) 1.5배(+60)·컨디션 +12/h·기분 +2/h. 에너지가 100이 되면 자동 기상(기분 +5, 아침이면 +10).
- 자는 동안 홈에 '완충까지 N분' 표시. 오프라인 중 완충되면 그 시점에 깨고 남은 시간은 깨어 있는 것으로 계산.
- 크로스핏 퀴즈(scripts/quiz.gd, 30문제): 3문제씩, 자는 중이면 '꿈속 퀴즈'. 하루 3번까지 보상(정답당 기술 +2 XP, 멘탈 +1, 기분 +3).
- 스트레칭 균형 게임: 12초 동안 A(왼쪽)/B(오른쪽)로 균형 유지, 초록 구간 7초면 만점. 컨디션 +8~30, 잘하면 기술 +2 XP. 에너지 소모 없음.

## WOD 방식 · 랜덤 WOD · 게임 시간 (v8)
- 게임 시간: 실제 1초 = 게임 8초 (WodGen.TIME_SCALE, v12에서 6→8). 시계·타임캡·AMRAP/EMOM 시간 모두 게임 시간.
- FOR TIME: 라운드×동작, 타임캡(기본: 라이벌 예상 시간 ×1.5). 캡에 걸리면 한 횟수만큼만 인정. 기록 = 시간(짧을수록 좋음).
- AMRAP: 정해진 분 동안 라운드 반복. 기록 = 총 횟수. 라이벌은 같은 시간 동안의 예상 횟수와 비교.
- EMOM: 매 분 동작을 교대로, 시간 안에 끝내면 남은 시간 휴식, 못 끝내면 실패. 기록 = 성공한 분 수, 전부 성공 시 보너스.
- 오늘의 WOD: 날짜+캐릭터로 고정된 랜덤 WOD. 랜덤 WOD 뽑기: 매번 새로(다시 뽑기 가능). 끝나면 내 WOD에 저장 제안.
- 생성 규칙(scripts/wod_gen.gd): 방식 확률 FOR TIME 42% / AMRAP 33% / EMOM 25%, FOR TIME의 20%는 칩퍼.
  해금된 동작 중 서로 다른 카테고리에서, 최근에 덜 한 동작 위주로 2~4개. 횟수는 조작 방식·단계에 맞춰 조절.
- 새 캐릭터는 기본 WOD 없이 시작.

## 조작 도움 (v9)
- 본체 버튼 힌트: 지금 눌러야 할 버튼에 노란 테두리, 타이밍이 맞는 순간엔 반짝임 + 빨간 화살표 (Screen.button_hints).
- 조작 방식(power/rope/cadence/combo/beat)을 처음 만나면 시간을 멈추고 설명 화면. 운동하기 → '조작 설명 다시 보기'로 초기화.
- 화면 터치: 한 버튼 동작은 아무 데나 = A, 두 버튼 동작(cadence/combo/beat)은 왼쪽 = B, 오른쪽 = A.

## 메뉴 편의성 (v10)
- 본체 버튼 아래 이름이 화면마다 바뀜 (Screen.button_labels): 홈 칭찬/상태/메뉴, 메뉴 다음/선택/뒤로 등.
- 모든 목록·폼 창 왼쪽 위 '◀뒤로' 터치 버튼, 목록 줄 높이 18px, 항목이 많으면 ▲▼ 터치로 넘기기.
- 메뉴 위에 메뉴를 열면 이전 창은 숨김(겹침 방지).
- 홈 바로가기 아이콘 줄: 밥 / 운동 / 잠(기상) / 케어 / 퀴즈 / 메뉴.
- 스트레칭 균형 게임은 실제 버튼 위치대로 B=왼쪽, A=오른쪽.

## 퀴즈 확장 (v11)

## 기본기 보강 (v13)
- 화면: stretch aspect keep_width. 세로로 긴 휴대폰에서는 늘어난 높이만큼 아래 본체와 버튼이 커지고(반지름 17~26), 바닥을 조금 띄움.
- 설정: 소리·진동 켜기/끄기(user://settings.json), 저장 백업, 게임 방법 다시 보기, 조작 설명 다시 보기, 처음부터 다시.
- 테스트 키(F1~F3)는 개발(debug) 빌드에서만 동작. GitHub Pages는 release 빌드.
- 저장 백업: 'WG1:' + base64(JSON) 코드 복사/붙여넣기, 웹에서는 파일 내려받기.
- 첫 안내 5장(게이지·바로가기·호출·가짜 배고픔·진화), 첫 호출 때 팁 1번.
- 부재중 호출 요약: 30분 이상 비우면 지금 필요한 것 + 꾀부림 추정 횟수. RX 이상은 진짜 필요를 무시한 호출로 기록.
- 진동: 운동 1회 성공, 실수, 호출 때 (지원 기기).
